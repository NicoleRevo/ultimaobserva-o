## Notas

Não foi fornecida URL de frame Figma para esta demanda. O protótipo foi
construído a partir de um screenshot de referência enviado pela usuária,
mostrando a tela de edição de uma Reunião ("Verificação de meta teste") no
módulo Reuniões da plataforma Target.

Elementos replicados a partir do screenshot:
- Cabeçalho da reunião (local, data, hora início/fim, instituição, tipo da
  reunião, redator) com tags de instituição/redator.
- Checkbox "Vincular aos encaminhamentos".
- Seção Participantes com busca e ausência obrigatória.
- Seção Assuntos: item numerado com ações (editar, duplicar, encaminhar,
  excluir), painel "Última Observação" (comentário anterior de outro
  usuário, com opção de fechar), editor de "Comentários" com toolbar de
  rich text, tabela de "Encaminhamento" (responsável, previsão, tipo) e
  ação "Adicionar Encaminhamento".
- Toolbar flutuante "Salvar / Cancelar" (modo de edição de observação).
- Seções "Assuntos Gerais" e "Anexos" (upload).
- Ação "Adicionar equipe de apoio".
- Rodapé com Voltar / Remover / Publicar + indicador de "Salvo às".
- Botão de ajuda flutuante no canto inferior direito.

Dados de pessoas/instituições no protótipo são fictícios (ex.: "Ana Souza",
"Instituição Exemplo"), diferentes dos nomes reais vistos no screenshot
original, conforme regra do projeto de não usar dados pessoais reais.
